- Prerequisites: Remind them they need the GitHub CLI installed (brew install gh) and need to run gh auth login and gh auth refresh -h github.com -s admin:org first.

- Configuration: Tell them to simply change the ORG_NAME, TEAM_SLUG, and STUDENTS variables at the top of the file.

- Usage: Show them how to make the script executable (chmod +x script.sh) and how to run it (./script.sh).
